# ml_workplace

This repository exists for one reason.

To make sure I never have to say,

> "I learned that once... I just forgot it."

Everything I learn, practice, and build ends up here.

## Layout

- `notes/` — distilled notes and reference notebooks, kept short.
- `exercises/` — topic practice notebooks (`NN_topic.ipynb`), grouped by module.
- `projects/` — self-contained end-to-end work; each keeps its own data.
- `resources/datasets/<module>/` — datasets shared by `notes/` and `exercises/`.

Setup: `pip install -r requirements.txt`, then launch Jupyter.
