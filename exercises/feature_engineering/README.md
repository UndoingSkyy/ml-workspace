# Feature Engineering

- `01_standardization.ipynb` — `StandardScaler` (zero mean, unit variance).
- `02_normalization.ipynb` — `MinMaxScaler` (rescale to a fixed range).
- `03_ordinal_encoding.ipynb` — `OrdinalEncoder` / `LabelEncoder`.
- `04_column_transformer.ipynb` — `ColumnTransformer` across mixed column types.
- `05_function_transformer.ipynb` — `FunctionTransformer` and power transforms.
- `06_sklearn_pipeline/` — end-to-end Titanic model, with and without `Pipeline`.

Datasets: `resources/datasets/feature_engineering/`.
