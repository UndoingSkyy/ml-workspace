# NumPy Notes — Index

Topic-focused notebooks in this folder, in learning order:

- `01_basics.ipynb` — array creation and basic properties
- `02_indexing_slicing.ipynb` — indexing and slicing examples
- `03_math_arithmetic.ipynb` — arithmetic operations and math functions
- `04_aggregation.ipynb` — sum, mean, std, var, min/max
- `05_random.ipynb` — random sampling, distributions, shuffling
- `06_reshaping.ipynb` — reshape examples and flattening
- `07_flatten_ravel.ipynb` — differences between `flatten()` and `ravel()`
- `08_transpose.ipynb` — transpose and axis reordering
- `09_resize.ipynb` — `np.resize()` vs `arr.resize()` (function vs method)
- `10_concatenate.ipynb` — concatenation and stacking examples
- `11_array_ops.ipynb` — split, append, insert, delete examples

Practice exercises for these topics live in `exercises/numpy/`.
